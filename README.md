# Spring Boot Microservices API

- RESTful APIs
- Service-layer architecture
- CRUD operations
- Modular microservice design

## 🛠️ Tech Stack

- Spring Boot
- REST APIs
- SQL

Demonstrates backend service development and API design best practices.
